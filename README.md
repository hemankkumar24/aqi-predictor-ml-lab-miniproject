# AirCast India - AQI Prediction with a Glowing India Map

AirCast India is a machine-learning application that predicts real-time Air Quality Index (AQI) right now across ~100+ Indian locations using live atmospheric measurements from the Open-Meteo Air Quality API. Trained on 5 years of Central Pollution Control Board (CPCB) historical air quality data (2015–2020), the project features a custom prediction playground with live city data autofill, a location-level gauge with health advisories, an interactive dark India map where severely polluted regions visibly glow red, and an environmental insights dashboard comparing regression models on unseen test data.

---

## Quickstart

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Train Models & Generate Artifacts
Automatically downloads `data/city_day.csv` (if not already present), trains 4 regression models, evaluates against a naive baseline, and saves `models.pkl` and `metrics.json`:
```bash
python train.py
```

### 3. Launch Streamlit Web App
```bash
streamlit run app.py
```

## Data Sources

1. **CPCB Historical Dataset (2015–2020)**: Central Pollution Control Board official daily monitoring records across Indian cities, hosted on Kaggle: [Air Quality Data in India](https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india).
2. **Open-Meteo Air Quality API**: Free, keyless global atmospheric model providing real-time hourly chemical estimates across Indian coordinates: [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api).
